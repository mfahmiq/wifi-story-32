# This Is Why Mom Left Your Dad

A Wi-Fi network name for the make.fun competition
[Tell a Whole Story in 32 Characters](https://make.fun/c/u-xvader-tell-a-whole-story-in-32-characters-f86dd978):
one SSID that lands a joke and implies a whole story in the few
words a passer-by sees in a phone's network list.

## The entry

> ThisIsWhyMomLeftYourDad

23 characters. It opens mid-accusation ("This Is Why"), delivers
the consequence ("Mom Left"), then swivels the blame onto the
reader ("Your Dad") — a domestic split, an unnamed dad, and an
unspoken incident the reader has to imagine for themselves.

## How to run

```sh
python3 main.py
```

This writes the entry verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). No network, no file reads, no secrets.
